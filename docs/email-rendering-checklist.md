## 邮件正文渲染验收清单

### Web（Bingmail）
- HTML 邮件：标题/段落/表格/按钮/图片不丢失，且页面不被外部样式污染
- 含 `<style>` 的邮件：基础排版可用（不再被整体剥离成“裸 HTML”）
- 纯文本邮件：展示全文（不再仅展示 snippet）
- Markdown 文本：标题/列表/代码块/链接可读，且不会执行 HTML
- 特殊字符：中文/Emoji/特殊符号无乱码
- 异常降级：当渲染报错时，仍能显示原始文本内容

### 安全与资源边界

- 恶意标签和属性：`script`、`iframe`、`form`、事件属性、`javascript:` URL、`srcset` 不可执行或绕过清洗
- 链接：邮件中的链接必须新窗口打开，并带 `noopener noreferrer`
- 外部图片：HTTP(S) 图片走同源媒体代理；私网地址、危险重定向、超大或非图片响应被拒绝
- 内联图片：`cid:` 只能改写到当前邮件的经鉴权附件端点；未知 CID 不得变成任意 URL
- 附件：非图片附件强制下载，不能以内联 HTML/脚本形式在本站 origin 执行
- 渲染隔离：确认 Shadow DOM 内的样式不会污染应用页面；不要将接口响应的 CSP 误认为前端阅读器的 CSP 沙箱

### 主流客户端（人工）
- Gmail / Outlook / QQ邮箱 / 网易邮箱：检查是否存在明显错位、字体异常、表格溢出、图片异常拉伸
- 移动端：检查长链接/长单词是否溢出，图片是否自动缩放至容器宽度
- Gmail / Outlook / QQ邮箱 / 网易邮箱的恶意或异常 HTML 样本：检查清洗后内容仍可读、不会跳转或弹窗
