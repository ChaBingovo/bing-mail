## 邮件正文渲染验收清单

### Web（Bingmail）
- HTML 邮件：标题/段落/表格/按钮/图片不丢失，且页面不被外部样式污染
- 含 `<style>` 的邮件：基础排版可用（不再被整体剥离成“裸 HTML”）
- 纯文本邮件：展示全文（不再仅展示 snippet）
- Markdown 文本：标题/列表/代码块/链接可读，且不会执行 HTML
- 特殊字符：中文/Emoji/特殊符号无乱码
- 异常降级：当渲染报错时，仍能显示原始文本内容

### 主流客户端（人工）
- Gmail / Outlook / QQ邮箱 / 网易邮箱：检查是否存在明显错位、字体异常、表格溢出、图片异常拉伸
- 移动端：检查长链接/长单词是否溢出，图片是否自动缩放至容器宽度
